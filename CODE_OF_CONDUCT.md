# Code of Conduct

## Our standard

Daymark is a small tool built for co-op work. Everyone who opens an issue,
a pull request or a discussion is expected to keep it useful and civil:
be patient with people learning the codebase, disagree with the code not
the person, and assume good intent.

## Unacceptable behavior

Personal attacks, harassment, trolling, publishing someone's private
information without consent, or any conduct a reasonable person would call
inappropriate in a professional setting.

## Enforcement

The maintainer (MitemsHub) may edit or remove comments, issues and pull
requests that violate this standard, and may ban repeat offenders. Report
problems by opening an issue marked private-friendly or contacting the
maintainer directly through GitHub.

## Scope

This applies to the repository, its issue tracker, discussions and any
space representing the project.
